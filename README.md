# Матрица судьбы — Telegram Mini App

Бесплатное приложение, которое считает восемь арканов по дате рождения и показывает разбор. Работает целиком в браузере: без сервера, без платежей, без внешних API и без LLM.

**Файл приложения:** `原型/V4 Матрица-судьбы-app.html`

---

## Что умеет

- **Матрица по дате рождения.** Одно поле с маской: набираете `14031991` — получаете `14.03.1991`. Расчёт мгновенный.
- **Восемь позиций.** Личность, энергия, финансы, предназначение, род, отношения, уроки, рост. Каждая раскрывается в текст.
- **Совместимость пары.** Вторая дата → две карты рядом, общие арканы, разбор общей точки.
- **История.** Разборы сохраняются на устройстве и открываются без повторного счёта.

Оплат, подписок и рекламы нет. Всё, что можно сделать, доступно сразу.

---

## Экраны и переходы

```
Главный
  ├─ ввод даты → Матрица (8 плиток + 8 блоков)
  │                 ├─ тап по плитке  → раскрывает свой блок и переносит выделение
  │                 ├─ тап по шапке   → закрывает блок и снимает выделение
  │                 └─ «Собрать пару» → Пара
  └─ «История» → История → тап по записи → Матрица
```

Навигация — стек: кнопка «Назад» в шапке возвращает на предыдущий экран.

## Совместимость пары

Отдельный режим, доступный из матрицы кнопкой «Собрать пару».

**Как работает:**

1. Своя матрица уже посчитана — её дата подставляется в подпись, повторно вводить не нужно.
2. Вводится одна дата партнёра, с той же маской и теми же проверками.
3. Считаются две матрицы: восемь чисел у каждой.
4. Находится **пересечение**: арканы, которые встречаются в обеих матрицах. Дубликаты убираются, порядок сохраняется, показываются первые четыре.
5. Результат:
   - две сетки по восемь чисел рядом, общие арканы подсвечены заливкой;
   - чипы вида `6 · Влюблённые` для каждого общего аркана;
   - разбор первого общего аркана — заголовок «Общая точка — N, Название» и текст о том, как это работает в паре;
   - если общих арканов нет — честное сообщение: близость строится на договорённостях, а не на совпадении.

**Ограничения режима:** своя дата не редактируется в этом режиме — вернитесь на главный и пересчитайте. Пара не сохраняется как отдельная сущность: в историю пишутся две даты и общие арканы, при открытии записи показывается ваша матрица.

## Расчёт

Свёртка: пока число больше 22 — вычитать 22; если получился 0 — считать 22.

| Переменная | Формула | Позиция |
|---|---|---|
| `a` | день рождения, свёрнутый | Личность |
| `b` | месяц | Энергия |
| `c` | сумма цифр года, свёрнутая | Финансы |
| `d` | свёртка `a + b + c` | Предназначение (ядро) |
| `e` | свёртка `a + d` | Род |
| `f` | свёртка `b + d` | Отношения |
| `g` | свёртка `c + d` | Уроки |
| `h` | свёртка `d + e + f + g` | Рост |

**Контрольный пример.** `14.03.1991` → `a=14`, `b=3`, `c=20`, `d=15`, `e=7`, `f=18`, `g=13`, `h=9`.

Арканы 1–22: Маг, Жрица, Императрица, Император, Иерофант, Влюблённые, Колесница, Справедливость, Отшельник, Колесо Фортуны, Сила, Повешенный, Смерть, Умеренность, Дьявол, Башня, Звезда, Луна, Солнце, Суд, Мир, Шут.

## Контент

Сейчас восемь блоков собираются из двух частей:

- **22 описания арканов** — по два предложения: сильная сторона и риск;
- **8 рамок позиций** — фраза вроде «Откуда берёшь силы и где теряешь».

Итого 30 заготовок вместо 176 готовых текстов (22 аркана × 8 позиций). Для теста и первых пользователей хватает, но тексты повторяются при разных датах. Следующий шаг — написать полную матрицу текстов и заменить сборку на прямой выбор.

## Данные и приватность

- Всё считается в браузере. Ни один запрос с датой рождения никуда не уходит.
- История лежит в `localStorage` под ключом `matrix_history_v1`, хранится последние 30 записей.
- Хранится только: дата, восемь чисел, тип записи и время. Ни имён, ни контактов.
- Очистка — удалить данные сайта в браузере или добавить кнопку сброса.

Политика конфиденциальности всё равно понадобится при публикации: дата рождения — персональные данные, а Telegram требует документ для приложений, которые их обрабатывают.

## Технически

- Один HTML-файл, около 37 КБ, без сборки и зависимостей.
- Единственный внешний запрос — `telegram-web-app.js` с `telegram.org`. Без него приложение работает как обычная страница: код проверяет наличие `window.Telegram` и молча пропускает вызовы SDK.
- Используются: `localStorage`, `navigator.share` (с откатом в буфер обмена), `HapticFeedback` в Telegram, `scrollIntoView`, CSS-анимации.
- Вёрстка: мобильный фулскрин, `100dvh`, safe-area отступы, максимум 520 px по ширине.

## Как запустить

**Локально:** открыть файл двойным щелчком. Работает и по `file://` — Telegram так не умеет, но для проверки логики достаточно.

**По HTTP:**

```bash
cd 原型
python -m http.server 8000
```

Затем открыть `http://localhost:8000/V4%20Матрица-судьбы-app.html`.

## Как опубликовать в Telegram

1. **Хостинг.** Переименовать файл в `index.html`, залить в репозиторий GitHub, включить Settings → Pages → Branch: main. Получится `https://логин.github.io/репозиторий/`.
2. **Бот.** `@BotFather` → `/newbot` → имя и username.
3. **Привязка.** `/mybots` → бот → Bot Settings → **Menu Button** → вставить HTTPS-адрес. Либо `/newapp` для карточки Mini App с коротким именем.
4. **Проверка.** Открыть бота на телефоне, нажать кнопку слева от поля ввода.

Требования: HTTPS с валидным сертификатом, адаптивная вёрстка, отсутствие запрещённого контента. Для каталога дополнительно нужны иконка 512×512, описание и скриншоты.

**Быстрый тест без хостинга:** `python -m http.server 8000` + `cloudflared tunnel --url http://localhost:8000`, полученный адрес вставить в BotFather.

## Как проверять после правок

1. Ввести `14031991` — маска даёт `14.03.1991`, расчёт даёт `15` в центре и `14, 3, 20, 7, 18, 13, 9`.
2. Тап по плитке «3 Энергия» — она получает класс `core`, у «Предназначения» он снимается; в документе ровно один `.tile.core`.
3. Тап по шапке открытого блока — блок закрывается, выделение снимается полностью.
4. Дата `31.02.1991` — поле краснеет и трясётся, расчёт не запускается.
5. Пара: `07.09.1988` → общие арканы `20`, `7`, `9`; при отсутствии пересечения показывается другой текст.
6. Перезапуск приложения — история на месте.

## Ограничения и рамки

- **Не диагностика и не прогноз.** Формулировки — «риск», «работает, когда», без гарантий. В интерфейсе нет слов «диагноз», «гарантирую», «точный прогноз».
- **Возраст.** Даты с возрастом меньше 14 и будущие даты отклоняются.
- **Нет синхронизации.** История живёт на одном устройстве.
- **Нет платежей.** Монетизация не предусмотрена — приложение бесплатное по замыслу.
